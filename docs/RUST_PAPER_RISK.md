# Rust 모의매매 위험 관리 원장 (2026-11-26)

## 범위

기존 정수 모의 원장과 SQLite 저널에 선택적으로 위험 정책을 연결한다.
Worker, 실시간 거래소 연결, private API, Python 원장 및 대시보드에 연결하지 않는다.
실주문에 적용할 수 있는 시스템이 아니다.

## 이벤트 계약

- 새 계좌의 첫 이벤트 `ConfigureRisk(RiskPolicy)`가 정책을 고정한다.
  기존 계좌에는 소급 적용하지 않으며, 설정하지 않은 기존 모의 원장 동작은 유지된다.
- 정책을 설정한 계좌의 매수 주문과 합성 매수 체결은 각각
  `GuardedSubmit`, `GuardedFill`로만 가능하다. 동일한 관측 프레임으로
  동작 전과 후의 손실/낙폭/노출을 검사하고 한도를 위반하면 원장과 저널을 변경하지 않는다.
- `ObserveRisk`는 현재 계좌를 평가해 실제로 관측된 위험 한도 위반 시
  매수 중단을 영구 기록하고 미체결 매수 주문을 원자적으로 취소한다.
  손실 한도와 낙폭은 한도 도달부터, 노출은 한도 초과부터 위반이다.
  실패한 가상 주문에 대한 사전/사후 검사 결과는 거래가 수락되지 않으므로
  관측 저널에 기록되지 않는다. 운영자는 주기적 `ObserveRisk`를 별도로 호출해야 한다.
- 매도와 취소는 기존 이벤트를 사용하며, 이미 가진 수량을 줄일 수 있다.
  매수 중단이 매도나 취소를 차단하지 않는다. 매도 후에는 새로운 관측으로 평가한다.
  `last_report`는 당시 관측의 기록이지 현재 시세나 계좌 상태가 아니다.
- 설정, 관측, 예약/체결, 중단 모두 기존 이벤트 체인과 트랜잭션에 들어간다.
  SQLite 재시작 및 논리 백업/복원에서도 동일하게 재생된다.
  기존 이벤트의 직렬화는 유지하되 새 variant를 이해하는 바이너리가 필요하다.

## 평가 공식과 단위

평가 가격은 **lot당 quote atom**이다. 시장의 원래 십진 문자열은 동일한
`MarketCatalog::mark_price_atoms`를 통해 변환할 수 있다. 사용자가 지정한
정책은 basis point(1%=100 bps), 통화/lot은 원장의 단위를 사용한다.

- 순자산 = 현금(예약액 포함) + 보유 자산 시가. 미실현 손익 = 보유 시가 - 수수료 포함 원가.
- 일일 손익 = 순자산 - UTC 일자 기준 자산. 최초 기준은 초기 현금이고
  날짜가 바뀌면 이전 유효 관측의 순자산을 기준으로 삼는다. 정확한 자정 평가가
  없는 경우 **표본 기준 추정치**이며, 장중 세션/거래소별 거래일이나 자정 가격을
  보장하지 않는다. 하루를 건너뛴 경우에도 직전 관측을 사용한다.
- 최대 낙폭은 초기 현금을 포함한 전체 관측 기간 최고 순자산 대비 하락폭이다.
  표시는 bps 내림, 제한 판정은 u128 교차곱으로 정확히 비교한다.
- 노출 = 보유 자산 시가 + 미체결 매수 잔여 lot × max(관측 가격, 지정가).
  수수료는 노출에 포함하지 않으며 실제 현금 예약은 별도 원장이 보장한다.
  매도 예약은 체결 전까지 노출을 줄이지 않는다.
- 현재 평가에 필요한 보유/미체결 매수 종목의 mark 누락, 0 가격, 미래 시각,
  최대 허용 지연 초과, 역행 시각 및 동일 source 시각의 다른 가격은 거절한다.
  평가 시각은 호출자가 공급하며, 1~24개(빈 계좌는 0개 가능) mark로 제한한다.
  동일 평가 시각은 완전히 같은 mark 프레임만 허용한다. 모든 연산은 checked 정수다.

## 안전 경계와 후속 작업

실제 시간/거래소 인증 및 신선도는 이 모듈에서 증명하지 않는다. 위험 이벤트의
입력 source timestamp와 평가 시각을 신뢰할 수 있는 공급자로 연결해야 한다.
잘못된 관측은 원장에 기록하지 않고 가상 매수를 거부하지만, 별도 지속적인
feed watchdog과 오류 시 정지 이벤트를 쓰는 감독기가 필요하다.
설정 값은 호출자가 정하며 기본 투자 한도를 추천하거나 강제하지 않는다.
시세 급등락 자체의 진위, 가격 band, 시가 평가 시 예상 청산 수수료/세금,
전략별 독립 자금, 거래일별 자정 valuation, 운영 전 카탈로그 단위 digest,
정기 관측 및 journal 용량 확장, 대시보드 연동은 미구현이다.
모의 계좌가 아닌 실거래 체결은 이 API에서 거부/취소할 대상으로 간주하면 안 된다.

```sh
cd apps/server

cargo test --locked
```

UTC 일자/최고 자산, 사전·사후 노출, 오래된/누락/미래 mark, 가상 체결 거부,
정수 범위, SQLite 백업·복원 재생을 다룬다. 이 문서는 테스트 범위이며
실행 성공을 주장하지 않는다.
