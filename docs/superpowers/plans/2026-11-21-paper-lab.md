# One-command Paper Lab Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans with independent
> parallel workstreams and a fresh final review. The user's repeated continuation
> authorizes execution and main publication; do not ask for a repeated approval.

**Goal:** Execute existing crypto, KRW/USD stock and order experiments through one
local command and explain missing broker configuration without exposing values.

**Architecture:** Compose existing audited engines and reports. Extend stock
smoke persistence, add an independent environment diagnostic and a thin lab
orchestrator. Retain coverage artifacts with optional external upload.

**Tech Stack:** Python 3.10+, existing dependencies, SQLite, static HTML, Actions.

**Spec:** [paper-lab design](../specs/2026-11-21-paper-lab-design.md).

## Global Constraints

- Fixed bundled synthetic inputs only; no live orders or authenticated requests.
- No currency aggregation or implicit FX conversion.
- Existing destinations refused; private new paths only; static failure messages.
- Diagnostic emits allowlisted variable names/presence only, never values.
- Required CI is preserved; publication uses the known remote SHA lease.

## Review Focus

1. An existing directory or dangling symlink must not be reused or replaced.
2. Missing/blank/malicious environment values must never leak or trigger network.
3. A component failure must leave no successful lab summary/index and restore guards.
4. USD results must come from an actual separate audited ledger and backup.
5. Exported HTML links must resolve inside the output and preserve synthetic context.
