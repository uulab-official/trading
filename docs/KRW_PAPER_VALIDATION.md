# 100만원 원화 모의검증

초기 자금 **1,000,000 KRW**를 `BTC/KRW` 가격으로 재생합니다. USDT 금액의
이름을 원화로 바꾸거나 환율을 추정하지 않습니다. 이 결과는 실제 과거 가격을
사용한 오프라인 모의 실행이며, 실제 잔고·체결이나 앞으로의 수익 예측이 아닙니다.

## 단위와 저장 호환성

- PaperExchange는 USDT 또는 KRW 중 한 통화의 현금·보유 자산·수수료를 계산합니다
- 초기 금액의 단위는 fixture의 심볼 quote입니다. `BTC/KRW`와
  `--initial-balance 1000000`을 함께 지정해야 100만원입니다
- 새 KRW book은 `version: 2`, `quote_currency: KRW`를 명시합니다.
  기존의 유효한 USDT book은 version 1과 기존 저장·결과 형식을 유지합니다
- 다른 quote의 주문·초기 보유량·수수료를 섞지 않습니다. KRW의 가격도 KRW
  quote를 요구합니다. 기존 USDT의 읽기 전용 가격 캐시는 유지하지만 다른 quote를
  사용하는 주문으로 보유 자산을 지출할 수 없습니다
- USDT 체크포인트를 원화로 바꾸지 않습니다. KRW 실험에는 새 저장 경로를 씁니다

로컬에 준비한 6열 OHLCV fixture로 실행합니다. 실행 자체에는 네트워크가 없습니다.

```sh
./test-trading.sh --fixture /path/to/krw-btc-fixture.json \
  --checkpoint data/krw-trial/checkpoint.json --initial-balance 1000000
```

같은 파일·옵션·저장 경로로 재실행하면 이전 기록을 검증하고 재개합니다.
프로그램에 실제 계정, API 키 또는 실거래 활성화 단계는 추가하지 않았습니다.

## 고정된 입력과 가정

[업비트 공식 분 캔들 API](https://docs.upbit.com/kr/reference/list-candles-minutes)의
인증 없는 시세 GET 응답을 별도 파일로 저장한 뒤, 네트워크·DNS·live adapter를
금지하고 원래 PaperRunner와 MA cross 3/5 전략을 실행했습니다.
프로그램은 데이터를 다운로드하거나 상시 시세에 연결하지 않습니다.

주 검증은 성과 계산 전에 정한 종료 시각 `2026-10-05T13:00:00Z` 직전의
완료된 1시간 봉 200개입니다. UTC 2026-09-27 05:00부터 2026-10-05 13:00
종료까지, KST 2026-09-27 14:00부터 2026-10-05 22:00 종료까지입니다.
누락 구간은 없습니다. 원본 응답 SHA256은
`7bcad07fc284c6541c0af8fdcfa5f1558d39bc8b696c2d26f1571940cda6efe8`입니다.

별도 과거 확인용 구간은 UTC 2024-12-23 13:00부터 2025-01-01 00:00 종료까지의
200개 봉입니다. 종료 시각 2025-01-01을 먼저 고정했으며, 성과가 좋은 구간을
선택하지 않았습니다. 2024-12-31의 봉 시작 시각은 17:00에서 21:00으로 4시간
떨어져 있으며, 그 사이 18:00·19:00·20:00의 시간 봉 3개가 없습니다.
가짜 봉으로 채우지 않았습니다. 원본 응답 SHA256은
`877efe203321d6fd92b430c94cd664e3870c7d01ddebb484dfd3ca9f6f2622c2`입니다.

시작 시각은 `candle_date_time_utc`에서 읽었습니다. API의 `timestamp`는 마지막
틱 기록 시각이므로 봉 시작으로 사용하지 않았습니다. JSON의 가격·거래량은 Decimal로
읽어 시간 오름차순의 완료 봉으로 정리했습니다. 원본 시세 파일은 저장소에 배포하지 않습니다.

두 구간 모두 기존 설정을 조정하지 않았습니다: 현금 20% 진입, 체결마다 수수료
0.1%, 불리한 방향의 슬리피지 0.05%, 다음 이용 가능한 봉의 시가 체결,
UTC 일별 신규 진입 중단 3%, 고점 대비 신규 진입 중단 10%입니다.
현재 [업비트 일반 KRW 수수료 안내](https://support.upbit.com/hc/ko/articles/36042119755929)는
0.05%를 참고값으로 명시하며 [별도 안내](https://support.upbit.com/hc/ko/articles/900006143046)는
이벤트에 따른 변경 가능성을 밝힙니다. 이 검증의 0.1%는 명시적인 모델 가정이며
사용자의 실제 계정·시점별 수수료와 같다고 검증하지 않았습니다.

## 관측 결과

금액은 원화이며 아래 표는 소수점 둘째 자리로 표시합니다. 저장본은 Decimal 값을 유지합니다.

| 항목 | 최근 고정 구간 | 별도 2024년 구간 |
| --- | ---: | ---: |
| 초기 자금 | 1,000,000.00 | 1,000,000.00 |
| 종료 평가자산 | 989,764.53 | 987,565.21 |
| 순손익 | -10,235.47 | -12,434.79 |
| 순수익률 | -1.02355% | -1.24348% |
| 수수료 | 7,154.50 | 6,342.36 |
| 모델 슬리피지 비용 | 3,577.25 | 3,171.18 |
| 봉 종가 기준 최대 낙폭 | 1.07650% | 1.70079% |
| 모의 체결 / 종료한 포지션 | 36 / 18 | 32 / 16 |
| 종료 BTC 보유량 | 0 | 0 |

수수료와 슬리피지는 이미 순손익에 들어 있으므로 다시 차감하지 않습니다.
종료 보유량이 0이므로 현금과 평가자산, 순실현손익과 순손익이 일치합니다.
두 구간에서 신규 진입 중단 임계값은 관측되지 않았습니다.
75개 봉 후 중단·재시작은 남은 봉을 진행해 무중단 결과·저장 상태와 일치했고,
이미 완료한 체결을 중복 실행하지 않았습니다. 이후 완료된 상태를 다시 실행했을
때는 새 체결이나 체크포인트 쓰기가 생기지 않았습니다.

## 체크리스트와 남은 범위

- 완료: 실제 KRW 초기 자금과 원화 가격·수수료·평가 계산
- 완료: 기본 USDT 저장 호환성과 통화 혼합·무단 단위 변경 거부
- 완료: 고정된 최근/별도 과거 입력의 출처·기간·간격 기록
- 완료: 100만원 실행, 순손익·봉 종가 낙폭 계산, 수수료·슬리피지 포함 확인
- 완료: 재시작 일치와 중복 체결 방지; 합성 급락 테스트의 신규 진입 중단/청산 허용
- 남음: 호가·유동성·지연·부분 체결·거래소 tick/lot/최소 주문·수수료 정산 호환성
- 남음: 더 긴 사전 고정 구간과 독립 검증, 상시 시장 연결 모의 운영, 대시보드 통합
- 별도 사용자 단계: 실제 계정·인증정보·실거래 활성화

낙폭 수치는 이 기간의 봉 종가 기준 관측값입니다. 설정한 3%/10%가 실제 손실의
상한을 보장하지 않습니다. 봉 내부 급변·갭에서는 임계값을 넘어서 손실이 생길 수 있습니다.
짧은 두 구간의 결과로 전략 수익성이나 실거래 준비 완료를 주장하지 않습니다.
