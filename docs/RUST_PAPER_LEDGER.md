# Rust 모의매매 경제 원장 — 2026-11-25

## 범위

새 `core::paper_ledger`는 실제 주문이나 시세 수신과 연결하지 않는 독립적인
결정론적 원장이다. 기존 Worker, private exchange API, Python 모의매매 원장,
대시보드 실행 상태는 변경하지 않는다. Rust live 실행 금지는 그대로 유지한다.

## 회계 계약

- 원장 하나는 고정된 quote asset 하나에 대한 모의 현물 계좌다. base asset은
  대문자 ASCII 영숫자 코드로 식별한다. KRW/USD/USDT 계좌는 별도 원장이어야 한다.
- 수량은 정수 lot, 가격은 lot당 quote atom, 현금과 수수료는 quote atom이다.
  외부 decimal 가격/수량을 변환하는 상품별 tick/lot/atom 계약은 별도 작업이며,
  단순 부동소수점 캐스팅이나 자동 반올림을 허용하는 의미가 아니다.
- 매수는 지정한 상한 가격 × 수량 + 총 수수료 상한을 예약한다. 실제 체결만
  현금 및 보유 원가를 바꾸며, 부분 체결 뒤 남은 수량과 수수료 한도만 예약한다.
- 매도는 이미 보유한 미예약 lot만 예약한다. 공매도·레버리지·마진은 지원하지 않는다.
- 매수 수수료는 원가에 포함하고 매도 수수료는 매도 대금에서 공제한다.
  부분 매도의 원가는 기존 원가 × 매도량 / 보유량을 정수 내림으로 배분한다.
  마지막 매도는 남은 원가를 모두 배분한다.
- 취소는 미체결 예약만 해제한다. 체결된 원가, 수수료, 수량은 되돌리지 않는다.
- 모든 연산은 정수 및 checked arithmetic으로 처리한다. 거절된 이벤트는
  계좌·주문·저널을 바꾸지 않는다. 외부에서 임의로 보유량을 수정할 수 없다.

## 위험 제한 및 복구

매수 주문별 비용, 종목별 보유 원가 + 미체결 매수 예약액, 보유/매수 예약
종목 수를 제한한다. 매도에 대한 보유 수량 예약은 중복 매도를 막는다.
세션 누적 **실현** 손익이 음의 손실 한도에 도달하면 추가 매수를 영구 중단하고
미체결 매수 예약을 취소한다. 수동 HaltBuys도 같은 동작이다. 매도와 취소는
계속 허용하며 이후 이익이 나더라도 중단 상태는 자동으로 해제하지 않는다.
이는 일중 손실 한도나 시가 평가 최대 낙폭 제한이 아니다.

수락한 이벤트 ID와 내용은 저널에 기록한다. 동일 ID/내용 재전송은 no-op,
동일 ID/다른 내용은 오류다. 주문 ID도 재사용하지 않는다. 원래 설정 및
수락된 이벤트 전체를 순서대로 replay하면 주문·현금·예약·손익·중단 상태를
복원한다. 저장 저널의 중복 및 잘못된 이벤트 순서는 오류다.
저널 자체의 유실/잘린 정상 prefix나 변조는 검출하지 않으며 SQLite 영속화,
원자적 commit 및 다중 writer 잠금, 외부 대사, 크기 제한은 아직 구현하지 않았다.
현재는 단일 소유자 및 상태 복사 방식으로 오류 시 원상 보존을 우선한다.

## 검증

```sh
cd apps/server
cargo test --locked --test paper_ledger_test
cargo test --locked
```

회귀 테스트는 예약 및 부분 체결, 비용/실현 손익, 취소, 잔고 및 중복 매도 제한,
가격/수수료/수량 위반, 손실 중단·수동 중단, replay, ID 충돌, 정수 overflow,
원가 정수 배분을 검증한다. 이 문서는 검증 명령 및 범위이며 통과 결과를
주장하지 않는다.
